Polymarket CLOB 凭据配置

使用 MetaMask / Rabby 签署官方 ClobAuth 消息。不导出私钥、不发交易、不向 Dashboard 上传凭据。

1 · 连接签名钱包

尚未连接

2 · 选择 Polymarket 持仓钱包

请在 Polymarket 网站核对该钱包的实际持仓地址。外部 EOA Signer 与 Safe/代理持仓地址可能不同。

如果显示的地址不是你预期的账户，不要继续。此工具不会自动证明账户映射正确，后续需要通过真实订单核验。

3 · 派生已有 L2 凭据

先尝试派生已有凭据，避免覆盖正在运行的交易机器人凭据。

4 · 放入 Cloudflare Secrets

只有收到完整 L2 三字段后才允许复制。Secret 名称按你选中的钱包顺序使用 CLOB_ACCOUNT_1、CLOB_ACCOUNT_2、CLOB_ACCOUNT_3。

粘贴到 Cloudflare 的 Secrets（加密），不要发聊天、邮件、Issue 或提交 GitHub。复制后立即清空剪贴板并关闭本地服务。

此页面仅绑定 127.0.0.1；页面请求只会发送至本机，本机服务只向官方 Polymarket CLOB 的凭据接口发起请求。
